# منصة أهداف التنمية المستدامة — الهيئة العامة للإحصاء

نموذج واجهة عربية متجاوبة لعرض أهداف التنمية المستدامة ومؤشراتها، مبني وفق هوية حكومية مستوحاة من كود المنصات الوطني.

## الصفحات

- `index.html` — الصفحة الرئيسية.
- `about.html` — نبذة عن المنصة.
- `methodology.html` — المنهجية.
- `goal-1.html` — صفحة الهدف الأول ومؤشراته وجداول بياناته.
- `admin.html` — لوحة إدارة المحتوى التجريبية.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة، أو تشغيل المجلد من خلال أي خادم ملفات ثابت.

## النشر على GitHub Pages

1. ارفع محتويات الحزمة إلى مستودع GitHub.
2. افتح إعدادات المستودع ثم **Pages**.
3. اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/root`.
5. احفظ الإعدادات وانتظر ظهور رابط الموقع.

## لوحة التحكم

لوحة التحكم نموذج تجريبي يحفظ المسودات والمحتوى المنشور في التخزين المحلي للمتصفح `localStorage`. لذلك لا تُعد نظام إدارة محتوى مركزيًا، ولا تتزامن بياناتها بين الموظفين أو الأجهزة.

للاستخدام المؤسسي يلزم ربطها لاحقًا بخدمة خلفية وقاعدة بيانات، وإضافة تسجيل الدخول والصلاحيات وسير مراجعة واعتماد المحتوى.

## الاستيراد والتنزيل

- تدعم لوحة التحكم استيراد `Excel` و`CSV` و`JSON`.
- يمكن تنزيل بيانات صفحة الهدف بصيغتي `Excel` و`CSV`.
- يمكن طباعة الصفحة أو حفظها بصيغة PDF من المتصفح.

## ملاحظات قبل الإطلاق الرسمي

- مراجعة المحتوى والأرقام والمصادر واعتمادها رسميًا.
- استضافة المكتبات والشعارات الخارجية داخليًا عند الانتقال إلى بيئة الإنتاج.
- اختبار إمكانية الوصول والأداء على الأجهزة والمتصفحات المعتمدة.
- تطبيق قالب ديناميكي موحد على الأهداف السبعة عشر.
